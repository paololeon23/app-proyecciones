# Q Berries · Proyecciones

App de campo para capturar cartillas de proyecciones (PWA).

## Uso local

Abre `index.html` en el teléfono o sirve la carpeta por HTTPS/local.

## Apps Script

Copia `gas/Code.gs` en tu proyecto de Google Apps Script y pega la URL `/exec` en `js/config.js` (`API_URL` o `_ep`).
